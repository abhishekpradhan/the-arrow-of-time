# Apollo 11 audio

Generated by `tools/assets/build_apollo11.py` from NASA's recording on its
[Historical Sounds](https://www.nasa.gov/historical-sounds/) page.

- `eagle-has-landed.wav` (48 kHz mono, 24-bit, 5.3 s): Neil Armstrong on 20 July 1969, moments
  after the lunar module Eagle touched down on the Sea of Tranquility: "Houston, Tranquility Base
  here. The Eagle has landed." It opens with the Quindar tone that ended Houston's "We copy you
  down, Eagle" (0.25–0.6 s); the words run from about 1.0 s to 4.9 s, over the hiss of the
  air-to-ground loop. *The Arrow of Time* plays it at cue `tranquilityBase`.
